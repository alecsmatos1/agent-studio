# Agent Studio

- No artificial limits (requested 2026-10-10, after a hidden 512 MiB memory cap took the relay down for 21 hours): nothing caps the size, number or duration of the user's content or work (messages, images, files, tool results and inputs, visuals, previews, plans, questions, forms, drafts, templates, uploads, relay requests and jobs, runs, sign-ins, imports, transcripts, screens) below what the machine, the operating system or the provider itself refuses, and nothing cuts it short silently. Never add such a limit; when a bound seems necessary, ask the user first. What stays: the relay's limits on requests made before sign-in (the pairing body and attempt rate), liveness timeouts that notice a stopped process, host or connection, correctness locks, caches, pacing, the live window a remote run's job keeps (everything still arrives with the synced chat), and display shortening of labels and alert lines.

See docs/SHARED-CONTEXT.md.
